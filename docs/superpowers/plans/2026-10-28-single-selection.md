# Single selection implementation plan

**Goal:** 推荐结果直接选定与收藏比较并行；选定只确认一次，保存必要需求并直接进入跟进，复用已有结果。

**Architecture:** 新增统一的选房上下文和原子提交服务，覆盖聊天、推荐目录和收藏入口。读取上下文不写入；确认时校验案例、会话及目录版本，在同一事务保存需求及选定结果。独立需求编辑只在筛选条件变化时更新一次结果。

- [x] 后端回归先覆盖未确认需求直接选房、收藏独立、缺项补填、重试幂等与版本冲突不产生部分写入。
- [x] 提取需求保存及结果复用逻辑；添加统一选房上下文和提交接口，保留旧接口兼容。
- [x] 前端统一确认框：地址、租金、条件摘要、仅缺失字段；一个“确认并开始跟进”按钮，不打开完整需求表。推荐目录及聊天可直接选房，收藏不构成前置条件。
- [x] 需求抽屉只需一次保存；相同筛选复用结果，变化筛选只追加一次有前后数量的更新；清理内部 Agent 确认报告输出。
- [x] 浏览器覆盖直接选定、收藏比较后选定、取消、缺项补填及不重复生成；执行相关后端、构建和完整主流程测试。
- [x] 重启本地服务验证数据保留，记录最终交互。
