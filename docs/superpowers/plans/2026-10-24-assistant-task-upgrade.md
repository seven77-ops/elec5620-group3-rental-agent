# Assistant task upgrade implementation plan

**Goal:** Implement the approved next priorities: personal housing comparison, chat-to-shared-lease-draft confirmation, and bounded multi-step read/query/enquiry work. Turn unavailable housing facts into inspection questions.

**Architecture:** Keep real-model intent recognition and deterministic database facts. Add server-derived comparison/enquiry/checklist presentation data and a bounded readonly workflow executor, rather than unrestricted model execution. Chat contract extraction reuses existing grounded lease extraction/calendar/schema/PDF services; proposals are source/version bound, explicitly confirmed, and atomically saved as ordinary shared lease drafts. Existing housing and legal unknowns remain unknown.

**Global constraints:** Preserve white/blue Ant Design, UI uses 房源 not 广告, current500-source catalogue, user's original case/runtime, legacy conversations and all existing Agent1–4 behavior. No paid map, new model vendor, fabricated commute/quietness/availability/price estimates, hidden budget changes, automated outbound messages, silent saves, or assumed current tenancy. No commits/publishing. External model calls outside DB transactions. Isolated runtime for all mutations/tests; main5191 updated after validation.
