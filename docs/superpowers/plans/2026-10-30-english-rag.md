# English-first rental knowledge RAG

Approved basis: the user's shared RAG proposal, six review corrections, and request to implement with English as the primary knowledge language. Execute in this session; keep user data and existing recommendation flow intact.

First deliverable: public English NSW rental documents, reproducible source snapshots, SQLite full-text + versioned vector retrieval, optional separately configured Bailian embedding/rerank, cited answers in existing chat and shared contract/aftercare knowledge panel. Private contract indexing remains separate: do not index cases or upload contracts under public-knowledge authorization.

1. Write failing provider/index/API tests: exact English queries, Chinese topic bridge, unknown questions, document replacement, vector model/dimension rejection, bounded transports, citation validation, safe no-model fallback, unknown-case rejection, consent, no business-state changes.
2. Add focused server/app/rag modules for independent HTTPS provider config, source/chunk/vector index, RRF retrieval, optional rerank, and answers. Persist vectors in SQLite alongside FTS for the small first corpus; use exact cosine, not approximate neighbors. Keep store boundary replaceable by Chroma later. Each source has captured/checked dates, hash, English section anchors and public jurisdiction. Network/indexing runs outside business SQLite writes. No private retrieval or arbitrary URL ingestion endpoint.
3. Capture English public documents from a fixed reviewed NSW Government source registry, with full source provenance and content hashes. Chunk by headings without silently truncating sections. CLI builds incrementally from snapshots, and --embed explicitly sends public chunks to configured provider. Preserve previous index on embedding failure; no network on ordinary startup.
4. Add case-scoped read-only status/search/answers/source routes. Search defaults local unless explicit external consent. Validate returned evidence IDs and exact quotes; invalid/failed generation falls back to viewable source excerpts, not an unsupported answer. No-answer returns no invented conclusion. Default answer language English, Chinese optional; knowledge originals always English.
5. Route public rental-knowledge intent to this service. Display backend-produced citations in chat and a reusable English knowledge panel on contract/aftercare pages. Preserve search/select/favorites and all matching listing IDs.
6. Add separate RENTAL_RAG_* settings and safe runtime status. After the user confirmed a shared key, absent/blank RAG keys reuse the active chat key, with explicit RAG override precedence. Retrieval URLs remain explicit local settings; they are never inferred from the chat URL. Test cloud adapters with real HTTP-shaped responses, and only claim real cloud verification if actual configured calls succeed.
7. Run backend regressions, focused browser tests and build; verify no case data mutation. Document capabilities, limits, source refresh/rebuild, local key configuration, public-only first scope and pending real provider setup.
