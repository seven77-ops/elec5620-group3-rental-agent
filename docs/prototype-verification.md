# 第一阶段原型验证记录

日期：2026-09-17。环境：本地 Python 3.13；代码目标为 Python3.10+，未在其他Python版本实跑。

更新：课程用例现统一为UC03／UC04（旧个人UC-01／UC-02只作为历史实现记录）。新增三份JSON Schema、逻辑推荐批次ID和显式选房后的本地证据包；完整规则与边界见[data-contracts.md](data-contracts.md)。当前运行增加本地jsonschema依赖，无网络调用。

## 交付范围

- 30条模拟房源、3份客户偏好。
- JSON导入/验证、三态硬筛选、四维加权评分、证据与缺失处理。
- Markdown/JSON报告、偏好调整前后比较。
- 课程F1/F2必须功能、F3可选功能（已实现），UC03/UC04文档与CLI测试；旧个人编号已迁移。
- 未接入真实房源、TfNSW、LLM或其他三个Agent。

## 测试过程

1. 先写23个核心测试，确认核心未实现导致失败；实现后23个通过。
2. 新增10个报告/CLI测试，确认未实现时失败；实现后定位并修复Markdown重复转义问题。
3. 独立只读审查发现枚举错误类型、极端权重溢出、超大整数及去重丢弃更新证据问题；先补回归测试复现，再修复。
4. 复审确认前述问题已解决，无新的critical/important问题。补充步行/换乘展示，并先看到对应测试失败再实现。
5. 补齐偏好不变、预算收紧、新目的地、时点变更等用例分支测试。
6. 新增契约结构/版本、确定性批次ID、明确选择、过期/篡改报告拒绝及本地证据包测试；按测试先失败、实现后通过推进。示例报告升级为1.1，评分保持不变。
7. 契约改动经独立只读审查，无critical/important问题；对比较历史的校验边界补充说明，并增加比较目标批次一致性检查。

运行命令：

```sh
python3 -m unittest discover -s tests -v
python3 -m compileall -q rental_agent tests
```

测试覆盖数以最新命令输出为准；此文档不把README里的第三方测试声明当作本项目实测结果。

## 保留的边界

- 当前只有本地工具核心，不应称为完整自主multi-agent系统。
- CLI默认拒绝覆盖；中断或磁盘错误可能留下部分输出，命令会报错，可用新前缀重试。
- 数值业务字段上限1e12；日期/格式错误拒绝整批输入，不静默修正。
- 模拟快照的来源权限和证据只是演示字段，不构成真实数据授权。
- 原有方案和用户修改均保留；没有提交、推送、合并或部署。
