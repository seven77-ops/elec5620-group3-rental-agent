# AI 接入本地运行与配置

本轮仅在 `codex/local-ai-integration` 本地分支开发，未推送 GitHub、未更新 PR/Jira。基线为已发布前端分支 `2e375bb`，保留真实 Agent 1 及原 Agent 4 流程。

## 打开本地页面

为避免与其他窗口运行的旧演示冲突，本次使用独立端口：前端 <http://127.0.0.1:5185>，API 文档 <http://127.0.0.1:8005/docs>。

在包含 frontend/server/agent1/agent2/agent3/agent4 的完整小组仓库根目录执行：

```sh
.venv/bin/python scripts/dev.py --web-port 5185 --api-port 8005
```

首次没有依赖时，按 [原运行说明](implementation.md) 创建 .venv、安装 server/requirements-lock.txt 和运行 frontend/npm ci。本次没有增加模型 SDK。默认启动命令不带端口参数时，仍使用 5173/8000。Ctrl+C 停止本次启动的两个子进程。

## 填写自己的 API

复制仓库根目录 `.env.example` 为 `.env`，在自己电脑填写：

```dotenv
RENTAL_AI_ENABLED=1
RENTAL_AI_URL=https://你的服务地址/v1/chat/completions
RENTAL_AI_MODEL=服务支持的模型名称
RENTAL_AI_API_KEY=你的密钥
RENTAL_AI_TIMEOUT_SECONDS=12
```

URL 必须是完整的 HTTPS Chat Completions 地址，具体路径按服务文档填写，不自动追加 `/v1/chat/completions`。当前实现兼容既有 OpenAI-compatible 消息/JSON响应格式，学校接口需要另外核对其文档。密钥只在后端使用，不填入前端或聊天，不提交 Git。

修改后重启启动脚本。脚本只读取白名单 AI 变量、不执行 .env 内容；终端已经设置的同名环境变量优先。通用 `RENTAL_AI_URL/MODEL/API_KEY` 中只要有一项非空就使用整组通用配置；整组均未填写时兼容既有 `AGENT3_MODEL_URL/NAME/API_KEY`，但仍需 `RENTAL_AI_ENABLED=1`。

配置开关默认为关。未配置时，页面显示“模型 API 尚未开启或配置完整”，AI按钮不启用，原有确认、推荐、合同复核及租后流程可以继续使用。API配置页只返回是否可用、模型名、协议类型和超时，不返回密钥或端点。

## Agent 2：推荐解读

新建案例 → 通过 Agent1 保存并确认偏好 → 生成推荐。在“AI 推荐解读”卡勾选本次外部处理同意，再点击“生成推荐解读”。查看每条推荐的辅助解释、原有 source_ref 和“本次 AI 调用”。分数、排名、资格及原报告不会被模型改写。零匹配时不发起模型请求。

## Agent 3：候选提取、规则预览与确认应用

1. 明确选择 DEMO-006，进入合同页，独立同意合同处理，下载并上传正常或冲突合成合同。
2. 上传先完成原规则复核。AI卡的外部处理同意独立于文件处理同意；勾选后点击“AI 辅助分析合同”。
3. 查看租金、地址、起止日期及租金周期/计价对象/币种候选，每项有原文引用、页码、行号。无法核对的字段标“待确认”，不能应用。
4. 查看按候选值生成的原规则预览，以及针对已有发现的AI解释。预览不改变正式状态；无发现时跳过解释调用。
5. 逐项勾选要应用的字段，核对原文后勾选确认，再点“确认应用所选字段”。真实改变才生成新复核版本，并使旧问题失效；值一致则不增加版本。
6. 修改原复核、选房/偏好，或撤销同意后，旧 AI 结果仍可读，但不能应用。切换到另一份 AI 分析时，字段勾选和核对确认会重置。

应用只更新用户选中的已验证字段；其余字段保持原复核值。AI不会自动审批、签约、确认租约或创建 M4 案件。原文引用校验能证明文字存在，不能自动保证模型解释的每一句语义都正确，仍需人工核对。

## 失败与重试

网络失败时保留原规则结果，重试沿用原 request_id 与输入。取消外部处理勾选会隐藏模型调用重试；重新勾选后才可重试。模型超时/响应非法会展示失败状态及真实调用详情；如需再次尝试，发起新请求。候选已经应用后遇到响应丢失，可重试原应用请求，后端返回原收据而不重复更新。

模型网络请求在数据库写事务外执行；每次调用前、结果提交时重新核对当前同意和输入。请求已发给外部服务后不能收回已发送内容。崩溃遗留的 pending 请求在90秒后允许同绑定重试；不承诺外部服务在崩溃恢复情况下严格只计费一次。

## 核对调用来源

正式页面没有产品模拟模型开关；配置后使用真实 HTTPS 服务。自动化测试单独启动 `server.tests.ai_demo_app`，例如使用独立8003/5183端口和独立存储；本轮最终复查使用8007/5187及生产预览4187，页面明确标为 `test_stub` / 测试替身；不能作为真实模型成功证据。

本次尚无实际模型凭据，因此真实外部 API 成功、学校服务兼容性和真实模型输出质量待配置后验证。测试结果及已知限制见 [AI 验证记录](2026-10-20-ai-verification.md)。
