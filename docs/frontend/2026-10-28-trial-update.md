## 下载与配置

保留个人开发内容，推荐另行克隆到新目录：

```sh
git clone --branch codex/group-trial-20261022 https://github.com/seven77-ops/elec5620-group3-rental-agent.git
cd elec5620-group3-rental-agent
python3 -m venv .venv
.venv/bin/python -m pip install -r server/requirements-lock.txt
cd frontend
npm ci
cd ..
.venv/bin/python scripts/dev.py
```

Windows 网站启动命令见[基本运行指南](2026-10-22-group-trial.md)。本轮实际验证为 macOS、Python3.13.2、Node22.23.1；没有 Windows 设备实测。网站默认打开 `http://127.0.0.1:5173`，端口冲突时可加 `--web-port 5197 --api-port 8017`。退出用 Ctrl+C，个人运行数据留在忽略目录 `.runtime/`。

已有干净试用目录可 `git fetch origin` 后确认分支并 `git pull --ff-only`；有未保存改动时先保留，勿用重置覆盖。

AI 与交通凭据仅填自己的后端 `.env`（从 `.env.example` 复制），不发群、不提交。AI 默认关闭，表单及本地库存查询可独立使用。真实聊天需配置已授权的兼容 Chat Completions 服务并同意当次处理。

### 可选 TfNSW MCP

- 先安装 `uv`，再运行 `.venv/bin/python scripts/setup_tfnsw_mcp.py`。MCP 上游要求 Python3.12+，在 `.runtime/tfnsw-mcp/.venv` 独立安装；不升级主网站依赖。
- 代码固定于 `maxim75/tfnsw_trip_planner_mcp` 的 `f020393ce6759b125f6198226c496a28c7822935`，源码、MIT许可证、依赖锁及 provenance 已保留。
- 配置本机后端 `TFNSW_API_KEY` 并启用 Trip Planner，`scripts/dev.py` 可管理本机6401侧进程；密钥按后端请求头提供，不传给侧进程环境。可用 `RENTAL_TFNSW_MCP_ENABLED=0` 关闭。
- 当前侧进程启动器使用 POSIX 的 `bin/python` 路径，本轮仅在 macOS 核对；Windows 侧进程自动启动不保证可用。Windows 未安装侧进程时仍保留网站和原 TfNSW 直连路线回退，不影响本地库存查询。
- 只开放路线、附近站点和运营提醒。附近站点/提醒依赖 MCP，失败会明示；提醒只针对所查站点，不表示整条未来行程正常。本次发布验证不重新安装上游或调用真实模型/交通服务。

## 主要更新

1. **库存与照片**：1,000套公开来源房源，72个区域，1,667个图片链接；本轮新增300套，原700条源记录保持不变。新增房源保留卧卫、车位、标价、来源、采集时间及匹配照片；照片可能因原站变化失效。
2. **悉大通勤**：统一 Fisher Library 官方设施点，852套有来源支持的楼栋位置，849套有采样时刻公共交通方案，开车/骑行/步行各852套；148套继续保留空坐标及粗估。未定位不伪造点位，范围门牌与精确地址分开。
3. **完整结果**：普通搜索返回全部匹配；20套以内默认展开，更多结果可展开并按20套分页。通勤结果有“全部/区域”过滤、12套分页及“换一批”。不主动要求到达时刻；明确提供时仍按原条件核对，每轮最多查询12套新路线，复用仅限同库存、完整条件和到达目标。
4. **结果与模型分离**：完整已展示结果均可引用、比较和明确保存；模型只获得有限首屏摘要及用户明确选择，避免把全部库存重复发给模型。偏好、报告和候选保留版本与确认校验；大报告同事务保存。
5. **简洁页面**：卡片显示多方式平均通勤参考，详情仅展示有数据的方式和地图链接；步行超过30分钟不展示也不计入平均。平均数不替代用户指定方式的硬上限。原广告链接收进详情，固定重复说明精简；未知事实仍保留在数据中，广告不代表当前可租或已确认租约。
6. **交通问答**：可查询已展示/保存房源附近站点及当前运营提醒；只发送公开房源位置，不发送租客/出租方送达地址。MCP不可用时路线回退至既有直连供应商，两者共享请求预算。
7. **需求接续**：短回答按当前追问推进，避免月预算仅因回答“每周”被直接改成相同金额周预算；用户实际需求和悉大通勤条件贯通确认及推荐页。普通助手生成默认temperature0.6，字段提取保持0。

## 发布复查修复

发现连续“换一批”会给复用路线套上新报告时间，延长原本30分钟时效。两项新回归在原代码上失败；修复后每条新路线记录查询时间，复用保留原时间，历史报告合并和候选匹配分别按原路线时间校验，展示证据时间也保留原值。相关16项测试通过，独立复查无剩余重要问题。最终全量结果另见下表。
