# 租约表单与官方 PDF 填写栏对齐

依据项目固定的 NSW Fair Trading 2026-09-21 标准模板（20 页、127 个字段），并核对官方当前模板网页。保留标准条款，不自动签署或确认附件已交付。

## 中介信息的定位

实际 v1 草稿已保存 `agent_name` 与 `agent_contact`，原映射写入官方第 2 页上半部 **Landlord’s agent details**。用户截图所见的下方空白属于 **Tenant’s agent details**，是另一种角色。现有字段保留原义，网站更名“出租方中介”，不把原中介信息复制给租客代理。

新增独立“租客代理”姓名、联系方式和通知地址（含 Suburb/State/Postcode），分别映射 Text field 2.21–2.26；出租方中介仍映射 2.15–2.20。无租客代理可留空。

## 完整草稿需确认的内容

以下是网站对完整草稿的填写清单，不表示每项在所有租约情形中都无条件法定必填。未知信息可先保存未完成草稿，并在 PDF 封面列出待确认项。

| 分类 | 填写内容 |
|---|---|
| 基础资料 | 房屋完整地址及区域/州/邮编、出租方姓名和直接联系方式、租客姓名/联系方式及通知地址、最多居住人数 |
| 租期与金额 | 租期类型、起租日、固定租期结束日、租金金额/周期、押金金额 |
| 付款 | 付款方式、付款说明、付款日、首期租金付款日期 |
| 费用和设施 | 是否另付用水费、嵌入式供电/供气、烟雾报警器类型、物业/社区规约 |
| 维修 | 电力与管道紧急维修联系人及电话；其他维修按需填写，填写任一项时提示补齐配对信息 |
| 通知 | 出租方与租客分别选择是否同意电子送达；只有明确选择“是”才填写对应邮箱 |
| 条件信息 | 有中介/租客代理时补齐该角色资料；出租方为公司时补公司登记资料；没有出租方代理时补出租方电话和通知地址；报警器可由租客换电池时填写电池类型 |

第二出租方、出租方不在 NSW 时的居住州/国家、拟定签约日期/地点保留按需填写。押金收取方标为“实际交付对象”，未交付时不要求选择；签字、收悉声明和附件交付不由草稿生成代为确认。

## 表单和 PDF 行为

- 用星号及条件显示提示完整草稿所需内容；仍允许暂存空白，不让网站默认为“不收费”“不适用”或已同意电子送达。
- 费用、设施、烟雾报警器及电子送达等选择需在表单手动确认，不交给 AI 自动选择。
- 更改选项后，不适用的隐藏邮箱/电池字段在新版本保存时清除，避免旧值写入 PDF。
- 新增公司出租方、押金实际收取方、水/电/气、烟雾报警器与电池、物业规约和双方电子送达的官方字段映射。
- PDF 保留完整 AcroForm 字段树、表单交互和空白签字栏。Radio widget 各自保留正确的外观状态，字段值从共享父字段继承，消除子控件冗余 `/V` 与主字段不一致。
- 旧 v1 不覆盖；修改后点击“核对并填入合同”并确认保存，生成新版本再预览。新字段默认空白，旧角色字段与来源保留。
