# 水电气网供应商卡片与详情弹窗

后续 UI 已更新为分类、搜索、网络筛选和分页套餐卡片，详见 `2026-10-28-utility-plan-browser.md`；下文记录最初的卡片到弹窗改造。

供应商主列表只显示名称、服务类型、覆盖范围及套餐/费率方案数量。整张卡片为原生按钮，支持点击和键盘 Enter；不会触发保存供应商选择。

点击后打开 Ant Design 详情弹窗，展示原有完整套餐、费率、适用条件、官方链接、联系方式及来源日期。较长内容在弹窗内部滚动，原有“查看其余方案”保留。关闭按钮、右上角关闭、Escape 均可返回列表并恢复卡片焦点。弹窗关闭后销毁详情内容，主页面不渲染套餐长列表。

改动集中于 `Utilities.tsx`、新组件 `UtilityProviderDetails.tsx` 和 `living.css`。普通供应商选择及确认保存逻辑不变；搬运/清洁页面和聊天推荐未改动。

验证：10 条浏览器测试通过，包括供应商详情、价格与来源完整性、390px 手机弹窗、键盘开关/焦点返回、未保存选择保留、原有租后服务流程。前端构建及格式检查通过，仅保留既有 vendor chunk 体积提示。截图位于 `/tmp/utility-provider-cards.png`、`/tmp/utility-plans-desktop.png`、`/tmp/utility-plans-mobile.png`。所有验证写入临时数据库；5191 运行页面已加载新组件，无需后端重启。
