# 租后服务资料展示优化

日期：2026-10-24（Sydney）。对应用户截图中的英文缺项错误和原始 JSON 抽屉。

## 变化

- 无退租计划且租约存在缺项时，展示中文清单与“补齐资料后生成计划”按钮，直接进入已有补填窗口，保留已选退租日期；不发送必然被拒绝的确认计划请求。
- 后端仍独立校验。返回 needs_clarification 时显示中文待办说明，错误代码、原文与请求编号收进“查看错误详情”。网络、版本冲突和原请求重试保留。
- 资料抽屉改为地址/来源概要、房屋概览、房间、家具清单和登记资料卡片；已知“无”和未知明确区分。随房家具存在但清单为空时仍标记缺项，即使旧资料中的核对开关为真也不会显示已齐备。
- 来源和证据类型使用中文名称。租约身份、版本、引用与证据仍保留在可展开的“查看原始资料”，不改动底层数据。
- 资料抽屉可直接打开补填窗口或登记资料。360px 屏幕宽度已验证，抽屉显示完整并可滚动。
