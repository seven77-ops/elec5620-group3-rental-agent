# 供应商详情弹窗 UI 优化

水电气网的供应商弹窗改为“概况与联系方式 → 套餐浏览 → 展开计价详情”的结构，沿用 Ant Design 与现有蓝白样式。顶部显示服务类型、覆盖范围、官网/联系页面/电话按钮及一次性的说明，减少在每张卡片重复展示的文字。

套餐按“全部 / 电力 / 燃气”等实际目录分类，提供套餐名称或网络搜索、适用网络筛选及每页 4 个方案的分页。桌面双列、手机单列，所有目录方案均可访问；筛选只影响当前弹窗，不保存供应商或推断住址适用性。切换供应商重新开始浏览。

紧凑套餐卡片保留套餐名称、网络标记、计费方式与主要费率。完整价格说明、其他计价行、适用条件、费用项目、官方编号与来源在“计价详情与适用条件”中展开。能源含 GST 的优惠前基准价说明集中展示，底层金额及数据未修改。

实现：`UtilityPlanBrowser.tsx`、`utilityPlanBrowser.css`、`UtilityProviderDetails.tsx`。`UtilityPlans.tsx` 导出可复用的 `UtilityPlanCard`，紧凑模式仅供详情弹窗使用；聊天推荐保留原有两张概览和其余展开形式。

验证：6 条浏览器用例通过，包括逐页收集并核对 AGL 全部 32 个方案 ID、分类/网络筛选、空结果与重置、完整费率/来源、手机布局、关闭焦点返回、未保存的供应商选择保留、聊天及服务详情回归。前端构建和相关文件格式检查通过，仅既有 vendor chunk 体积提示。所有写入测试使用临时数据库；本地 5191 已加载新界面，无需后端重启。
