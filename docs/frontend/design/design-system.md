# Frontend design system

Approved source: 2026-10-17-frontend-plan.md. Generated supporting concept: recommendations-concept.png, built-in Image Gen UI mockup (2026-10-17). The approved written plan remains authoritative for business semantics and required states; concept facts are illustrative only and actual server data always wins.

Tokens: cool-gray background #F5F7FA; white surfaces; navy #172B4D; secondary #65758B; border #E4EAF1; primary blue #174EA6; accent teal #087F8C. Sans-serif system stack with PingFang SC/Microsoft YaHei. 28px page titles, 16px content, 14px secondary, 12px metadata. 8px spacing scale, 8px corners, almost no shadow.

Layout: white 68px header, 208px sidebar, 32px main padding. At wide recommendation pages optionally a 208px context rail; hide at tablet. Lists use aligned row anatomy: rank and ID, score, three facts, explanation, evidence and selection actions. No photography, gradients, maps or decorative art.

Icon family: Ant Design outlined home, app grid, form, document, checklist, information; 18px navy, active blue. Buttons 40px tall; outlined secondary, filled primary. Evidence is a right drawer/fullscreen on mobile. Mobile main padding 16px, collapsible navigation, stacked facts/actions. Explicit focus ring, labeled controls, reduced-motion support.

Above-fold copy: 租房助手, 合成数据演示, 我的进度, 租房偏好, 房源推荐, 合同复核, 租后服务, 演示与证据, 修改偏好, 查看推荐依据, 选择此房源. Required case identity, actual statuses, timestamps, errors and route-specific content come from the approved written plan.

Intentional deviations from concept: scores/fees/commute/list IDs use actual server outputs, not generated sample text; responsive layout adapts to 360/768/1440px; required version selector/export controls and accessible status text are added to support the approved workflows. The written plan does not require the concept's optional right rail at small widths.
