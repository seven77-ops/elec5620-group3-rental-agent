## 下载与运行

推荐另行克隆到新目录，保留自己的未保存开发内容：

```sh
git clone --branch codex/group-trial-20261022 https://github.com/seven77-ops/elec5620-group3-rental-agent.git
cd elec5620-group3-rental-agent
python3 -m venv .venv
.venv/bin/python -m pip install -r server/requirements-lock.txt
cd frontend
npm ci
cd ..
.venv/bin/python scripts/dev.py
```

Windows PowerShell：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r server/requirements-lock.txt
cd frontend
npm ci
cd ..
.\.venv\Scripts\python.exe scripts/dev.py
```

打开 `http://127.0.0.1:5173`；端口占用可加 `--web-port 5197 --api-port 8017`。退出用Ctrl+C。已有干净试用目录可确认分支后 `git fetch origin`、`git pull --ff-only`；勿重置覆盖个人修改。

复制 `.env.example` 为自己的 `.env`，仅在后端填写已授权AI/TfNSW凭据，勿发群或提交。AI默认关闭，不配置可用手工页面和本地库存。可选MCP配置及独立环境步骤见[10月28日说明](2026-10-28-trial-update.md#可选-tfnsw-mcp)，上游要求Python3.12+及uv；侧进程启动器仍为POSIX路径，Windows自动MCP未实测，可使用网站及原直连回退。本轮macOS/Python3.13.2/Node22.23.1验证，没有Windows设备实测。

本机案例在忽略目录`.runtime/`，不会随Git提供。165条套餐种子会幂等导入运行目录独立的utility_catalog.sqlite3，保留旧内容快照，与案例库分开。

## 当前用户流程

1. **按参考通勤找房**：找房只使用方式、分钟上限和可选换乘要求，不收集或沿用历史到校时刻/日期。来源路线仍有自己的时效，估算区间按上界满足限制，缺数据不补造。卡片/详情按所选方式显示时间或范围，替代旧跨方式平均数；地图为普通URL，无付费Google API。
2. **直接修改工作条件**：聊天顶部“本次找房条件”可点选修改，明确应用后重算全部匹配并显示变化，刷新保留工作会话；不会偷偷改已确认需求、收藏、选定房源或合同。零结果给出预算+50、通勤+10、区域不限的真实计数，每个只改一项，仍为零的方案不能应用。未点击不会放宽条件。
3. **数据支持的推荐理由**：按当前整套可比预算、所选交通和房型计算差额/理由，不用个人或单间预算冒充整套租金，不编造缺失交通或满足条件。明确短句如“公共交通20分钟”优先保留用户本轮改动，否定/问句/复杂备选仍走原意图路由，不改写旧消息。
4. **收藏与直接选定并行**：可以先收藏多套、按地址/区域筛选并比较2–4套；也可直接“选定并跟进”，收藏不是前置要求。只出现一个确认框，已有条件带入，必要缺项在框内补齐；确认后同事务保存需求和当前房源，取消不写。替换选定不清空收藏，取消收藏不删跟进记录，旧合同/记录保留。选定不代表签约或已核实租约。
5. **需求一次保存**：“我的租房需求”主动保存不再二次确认；相同筛选复用已有卡片，实际变化只追加一次结果更新。版本、案例归属、目录变化和幂等校验仍保留。
6. **合同表单及PDF**：出租方中介与租客代理独立；付款、公司出租方、设施/报警器、电子送达等条件字段与项目固定模板对应。未知可存未完成稿，相关选择由用户手动确认；隐藏旧值在新版本清理，PDF字段树/Radio外观、历史版本和空白签字保留。
7. **报修AI润色**：原稿、称呼、可空主题、语言/语气→AI润色→用户编辑/复制→确认保存。只把当次相关字段发给模型，不带合同/聊天/附件；生成不自动建案，失败保留输入和请求重试，邮件始终未发送。
8. **水电气网及服务商**：9家供应商165条官方来源套餐/费率记录，含费率变体，非全市场。SQLite版本化、促销/恢复价、独立时效、配网/电表、完整计价和来源保留；不缺用量估算月账单。供应商详情可分类、搜索、按网络筛选，每页4条。搬运12家、清洁12家按组浏览，详情查看简介/官网，再在同一弹窗记录个人报价；不替用户预约或付款。

库存仍为1,000套/72区域，本次源房源文件没有变化，不重复计入新增房源。852楼栋位置、849采样公共交通、148空坐标粗估以及1,667图片链接继续保留，广告不认证当前可租。

## 发布复查修复

- **预算口径不一致**：个人/每间预算在推荐时不限制整套广告，却在新选定入口按整套上限拒绝。两项API回归在原代码失败；保存需求时把预算映射同步为每周整套可比或matching_scope，选定及后续页面保持一致。回归还验证改回整套900时恢复上限。
- **确认显示历史资料**：旧卡片可能显示旧地址/旧租金，但token绑定当前目录。确认框改为显示当前preview房源；地址/租金变化时提示核对。已补浏览器回归代码，实际CUA隔离页先复现旧地址/AUD1，再验证当前公开地址/AUD320与更新提示，只有明确确认才开始跟进。

相关15项后端检查通过，独立复查无剩余P1/P2。最终全量及构建结果见本页末尾。上述小修复仅在源文件指纹一致后同步回开发目录，保留其他窗口工作。
