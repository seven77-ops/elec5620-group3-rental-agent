# 合同助手：NSW 租约草稿

2026-10-22，本地预览已接入。真实房源模式的 Agent3 导航改为“合同助手”，包含“生成租约草稿”和“上传合同复核”。候选跟进卡和 AI 对话均可进入对应模式；原有合同提取、交叉核对、人工复核继续保留。

## 用户流程

1. 保存真实候选，打开“生成租约草稿”。地址可来自候选广告，已有看房记录中的明确事实可预填，并标明来源。
2. “直接填写合同信息”是主操作，按房屋信息、租赁双方、租期与租金、付款信息分组；代理信息按需展开。广告标价、搜索预算、默认租期及人数均不会自动成为合同约定。第一版仅支持 NSW 普通整租住宅，需明确确认适用范围。
3. “AI 辅助填写（可选）”默认收起，可独立同意将本次描述发送给外部 AI，提取字段并列出待补问题。AI 只接收这段描述及字段结构，返回建议须有原文依据；用户查看并应用后才填入表单，不会自动保存，也不生成任意法律条款。
4. 确认弹窗核对实际填写内容，再保存草稿。允许保存资料未齐的版本，缺失内容会列在页面及 PDF 封面中。
5. 点击“核对并填入合同”，确认保存后自动打开已填写的官方 PDF 预览，可返回修改或下载该版本。再次修改表单时明确提示预览、下载仍为已保存版本；预览本身不保存任何数据。旧版本可查看、下载；候选或来源版本变化后，旧草稿不再作为当前来源继续编辑。

草稿独立保存，不改变已选房源、需求确认、合同复核或租后记录，也不表示房东已同意条款。

## 官方模板与导出

- 来源：[NSW Standard residential tenancy agreement](https://www.nsw.gov.au/housing-and-construction/rental-forms-surveys-and-data/resources/standard-residential-tenancy-agreement)。
- 固定模板：`agent3/data/templates/nsw-residential-tenancy-2026-09-21.pdf`，20 页，表内版本标注 **21 September 2026**；来源及校验值保存在同名 JSON。
- SHA256：`5addb961d6864a794f1f5e44a74e21e5216e762eeeac9e176ec088c004480c64`。
- 标准条款保留，填写明确映射的官方交互字段；中文字段有可见外观和字体资源。添加草稿封面及每页未签署标识，签字、声明勾选及未知选项不自动填写。通常导出 21 页，封面较长时可增加页数。
- 导出后重新读取并验证字段值、控件外观及空白签名；模板校验失败时拒绝导出。
- 为接收完整模板，真实模式文字 PDF 复核上限为 30 页；扫描件 OCR 仍为 10 页，历史 CLI 默认上限仍为 10 页。

## 接口与状态

以 `/api/v1/cases/{case_id}/lease-drafts` 为前缀：

| 接口 | 功能 |
| --- | --- |
| `GET /context` | 当前候选、确认需求及跟进记录的来源指纹、保守预填及模板信息 |
| `GET /` | 草稿列表及版本摘要 |
| `POST /` | 明确确认后保存；请求 ID 去重、来源指纹与预期版本校验 |
| `GET /{draft_id}?version=N` | 精确读取历史版本及冻结来源 |
| `GET /{draft_id}/pdf?version=N` | 下载该版本的未签署交互式 PDF |
| `POST /proposals` | 独立同意后的 AI 字段建议；不写入草稿 |

草稿及版本均按案例鉴权。AI 调用前后检查来源，外部模型执行时不持有数据库事务；保存使用独立记录、不可变版本和请求回执。
